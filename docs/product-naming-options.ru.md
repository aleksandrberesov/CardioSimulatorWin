# Варианты названия продукта — Кардиосимулятор

Дата: 2026-09-03
Контекст: текущие рабочие названия — "ESG Master" (вероятно, опечатка от "ECG Master") и общее "кардиосимулятор" / "Cardio Simulator". Документ собирает рассмотренные варианты названия с обоснованием — для обсуждения с партнёром.

## Рекомендация

**RhythmiQ** — рекомендуемое основное название для международного рынка.

- Придуманное слово (Rhythm + IQ): передаёт две ключевые сильные стороны продукта — распознавание ЭКГ-ритмов и адаптивное/интеллектуальное обучение.
- Нет известных конфликтов товарных знаков в области кардиологии/медтеха.
- Легко произносится на английском, немецком, испанском и других языках, актуальных для международных медицинских вузов и клиник.
- Естественно масштабируется в суббренды, совпадающие с существующими режимами приложения: `RhythmiQ Monitor`, `RhythmiQ Teaching`, `RhythmiQ Treatment`.

**Предлагаемый брендинг:**
- Полное название: `VLN RhythmiQ` или `RhythmiQ by VLN Advanced Health Simulations`
- Тэглайн (EN): *"Master cardiac rhythms with confidence"* или *"Where rhythm recognition becomes intuition"*
- Домены для проверки в первую очередь: `rhythmiq.io`, `rhythmiq.app`, `getrhythmiq.com`

**Перед окончательным решением:** проверить реестры товарных знаков (WIPO Global Brand DB — для международного рынка, Роспатент/fips.ru — если планируется отдельный SKU для российского рынка) и доступность доменов.

---

## Почему не оставить "ESG Master" / "ECG Master"

Названия вида "ECG" + общий суффикс ("Master", "Pro", "Trainer") крайне распространены среди существующего софта и оборудования для обучения ЭКГ. Низкая уникальность затрудняет регистрацию товарного знака и снижает узнаваемость бренда в поиске. Рекомендуется перейти на самостоятельное, юридически защитимое название.

## Полный список рассмотренных вариантов

### Международные (латиница / англоязычные)

| Название | Обоснование |
|---|---|
| **RhythmiQ** ⭐ рекомендовано | Rhythm + IQ — распознавание ритмов + адаптивный интеллект; уникальное, конфликтов не найдено |
| **Cordis** | Лат. *cor/cordis* = «сердце». Короткое, премиальное, легко произносится международно. **Риск:** конфликтует с Cordis Corporation (Cardinal Health) — известным брендом кардиоваскулярных устройств (стенты, катетеры) в той же медицинской области — реальный риск по товарному знаку/бренду. Не рекомендуется без юридической проверки. |
| **CorPulse** | «Сердце + пульс». Энергично, хорошо ложится в логотип с пульсовой волной. |
| **SinusLab** | Отсылка к синусовому ритму (базовое понятие ЭКГ) + «лаборатория» практики. |
| **VectorCor** | Связь с модулем электрической оси сердца (ЭОС) в приложении + «сердце»; более техничное позиционирование. |
| **PulseForge** | «Кузница пульса» — сильный, «тренажёрный» тон. |
| **CardioVista** | «Обзор сердца» — мягкое, премиальное звучание. |
| **EchoRhythm** | Ритм + «эхо», отсылка к обратной связи/циклу обучения. |
| **MyoCore** | *Myo* (мышца) + core — техничный, клинический тон. |
| **CardioSim Pro** | Рассматривался, но отклонён — слишком общее название, та же слабость, что и у "ECG Master". |

## Чек-лист перед окончательным выбором названия

1. **Проверка товарных знаков** — WIPO Global Brand DB (международно) и Роспатент/fips.ru (если в планах есть российский рынок).
2. **Доступность доменов** — проверить `.io`, `.app`, `.com`, `.ru` для 2–3 финальных вариантов.
3. **Произносимость** — проверить на английском и русском, а также на языке любого другого целевого рынка.
4. **Отсутствие пересечения с реальными брендами медицинского оборудования** — особенно важно в кардиологии (см. примечание про Cordis выше).

## Техническое примечание по внедрению

В приложении уже есть единая точка ребрендинга: константы `AppBrand*` в `Directory.Build.props`, при этом `AssemblyName` отделён от пространства имён C#, плюс есть миграция папки данных при первом запуске после переименования. После окончательного выбора названия применение его по всему приложению (заголовок окна, экран «О программе», инсталлятор) — небольшое, локализованное изменение, а не рефакторинг.
